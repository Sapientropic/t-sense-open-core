# Documentation Map

This docs folder is for public open-core material only.

- [getting-api-credentials.md](getting-api-credentials.md): Telegram API setup
  troubleshooting.
- [tos-risk-analysis.md](tos-risk-analysis.md): practical risk notes for local
  Telegram scanning.
- [licensing.md](licensing.md): AGPL community license and commercial licensing
  policy.
- [demo.mp4](demo.mp4) and [screenshots](screenshots/): public report demo
  assets.

Do not add private product strategy, market research, user research, private
datasets, generated reports, sessions, credentials, private product
internals, or recommendation specs here. Keep those in private repositories or
gitignored local folders.
